# Omarchy Shinchan Theme

A custom Shinchan-inspired theme for [Omarchy Linux](https://omarchy.org/).

## Previews
![Preview](preview.png)
![Lock Screen](preview-unlock.png)

## Installation

You can install this theme directly using the Omarchy CLI:

```bash
omarchy theme install https://github.com/oz456/omarchy-shinchan-theme
omarchy theme set shinchan
```
