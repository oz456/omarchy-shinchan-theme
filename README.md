# 🍙 Omarchy Shinchan Theme

> *"To be playful is not childish — it is the highest form of mastery."*

A bold, high-contrast dark theme for [Omarchy Linux](https://omarchy.org/) inspired by the irreverent, sarcastic spirit of Crayon Shin-chan. Designed with **DHH-style ruthless clarity**: zero unnecessary visual noise, a deep warm obsidian backdrop, and punchy semantic accents that make your terminal pop.

![Preview](preview.png)

---

## 🎨 The Aesthetic

- **Deep Warm Canvas (`#120E0C`)**: A soothing, warm dark background engineered for prolonged coding sessions without eye strain.
- **Action Bastard Gold (`#F2C14E`)**: The signature focus accent. Active window borders, prompt glyphs, and tabs glow with high-contrast energy.
- **Shinchan Shirt Crimson (`#E63946`)**: High-priority alert and diagnostic highlights.
- **Chocobi Palette**: Pure semantic terminal colors tailored for fast readability across Neovim, Ghostty, Kitty, and Btop.

## 🚀 Installation

Install directly with the Omarchy CLI:

```bash
omarchy theme install https://github.com/oz456/omarchy-shinchan-theme
omarchy theme set shinchan
```
